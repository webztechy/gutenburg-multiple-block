Adds an Multiple Blocks to Gutenberg with configurable columns, spacing, rounded corners, and optional captions.

== Installation ==
1. Extract this plugin folder into wp-content/plugins/gutenburg-multiple-block.
2. In the plugin folder, run `npm install`.
3. Run `npm run build`.
4. Activate Advanced Gallery Block in WordPress Admin > Plugins.
5. In the block editor, add the “Multiple Block” block from the Media category.

== Development ==
Run `npm start` while developing to rebuild assets automatically.

== Notes ==
This starter plugin uses the WordPress Media Library. The production frontend is responsive and includes lazy loading.
